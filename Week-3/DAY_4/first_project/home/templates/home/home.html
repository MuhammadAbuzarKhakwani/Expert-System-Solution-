System overview

Built to hold the whole academic record, without the clutter.

Four modules, one database, no duplicate spreadsheets floating between departments.

01

Enrollment

Add, edit, and archive student profiles with a clean Django admin backing every field.

02

Attendance

Mark daily attendance per class and roll it up into a term-long picture automatically.

03

Grading

Record assessments, compute GPA, and keep transcripts consistent across semesters.

04

Reporting

Generate class and student-level reports on demand, exportable for the registrar's office.

05

Access control

Role-based permissions so faculty, admin staff, and students see only what's theirs.

06

Audit trail

Every change to a record is logged, so nothing gets edited without a trace.
